# 0020 A clear first minute and bounded replies

Date: 2026-10-09. Status: accepted within Ahmed's request to finish and improve
the full project, followed by independent Astra judge and user reviews.

## First minute

Explain the steps-to-energy promise before the controls. Judge mode offers a
4,000-step simulated walk. Put conversation before the advanced day controls.
Desktop can show the world and conversation side by side. Simulations remain
labelled in the interface and exported cards, including when a busy live-demo
pool falls back to sample replies. Real owners never silently become demo pets.

An optional "Take a moment" dialog offers a fixed sensory invitation and pauses
world animation. On heat days it invites staying comfortable indoors. Returning
opens the existing conversation. No timer, goal, location, note, or automatic
message is recorded. This adds a reason to leave the screen without changing
the energy engine or pretending the person has walked outside.

## Reliability

Reset and day controls cancel any queued slider update. Sending a reply waits
until a queued feed finishes. Reset cancels both the visible reply and the
network request. Late responses cannot update a newer pet. API failures retain
the real pet's credentials and show recovery controls.

The model's readiness means visible reply text, not role or reasoning metadata.
Whole-request deadlines cover stalled response bodies and outgoing writes.
Cancelling a stream releases its upstream reader. These changes must preserve
single charging and generation fencing, with regression tests.

The energy goldens remain unchanged. When growth expands capacity, explain that
the existing energy now fills a larger body; never describe the percentage drop
as lost steps. Heat rewards acknowledge received steps without praising heat
perseverance or claiming to know where the person walked.
