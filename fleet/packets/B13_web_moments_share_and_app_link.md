Spec:
1. Moments. On every summary, find moments with id above the last shown id (persist last id in localStorage per phrase). 2. Share card. A "share" button renders a 1080 x 1350 PNG on an offscreen canvas: the current world as text (read the visible `<pre>` layers or ask the world for its frame via an existing export if there is one; if the world has no frame export, render the HUD and the pet rows you can read from the DOM) on the palette background, the HUD line, the newest moment line, and "truffle, a pet that eats steps" with the URL. Use `navigator.share({files})` when available, else download. No external libraries. Nothing leaves the device except through the user's own share sheet.
3. Credentials from the app: on load, if `location.hash` matches `#creds=<phrase>.<secret>` (phrase is three list words with hyphens, secret is the format api.ts expects), store them the way main.ts stores credentials, then `history.replaceState` to strip the hash before anything else runs. Add a test for the parser.
4. App hand-off: on Android user agents, when not already inside the app's WebView (the app sets a user agent suffix `TruffleApp/0.2`), show a small "open in the Truffle app" link that goes to `truffle://pair?creds=<phrase>.<secret>` and a link to the GitHub release. Inside the WebView, hide the pairing UI the app does not need and never show the link.
5. Keep the DOM sink test green (no innerHTML with untrusted text). Keep reduced motion behaviour. Keep RTL for Arabic.
Acceptance: `cd web && npm test` green (54 existing plus yours), `npm run build` clean, a screenshot of a moment line and of a share card PNG in fleet/outbox/B13/ (use the mock backend with `?mock=1` if that exists, else describe how you drove it; the chrome-devtools tools are available to you).
